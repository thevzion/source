# Build the dashboard

The loop that observes is what was missing: a system that writes but never measures itself only
shows a growing page when someone happens to read it.

The dashboard is a projection of `space.md`, `objects/` and `git log`, launched from the repository
in one command, without an account or a network. It shows the [measures](https://github.com/thevzion/standard/blob/main/standard/measures.md)
and blocks nothing ([trial 11](https://github.com/thevzion/standard/blob/main/tests/trials/11-dashboard.md)).

Open: [its stack](../questions/dashboard-stack.md).

**Done when** it runs on this repository and shows the structure measures that `git log` and
`objects/` allow.
