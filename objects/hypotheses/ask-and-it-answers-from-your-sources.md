# Ask, and it answers from your sources

A view is a question asked of the sources. A pure agent sees only its sources, answers from them,
and returns a question when they don't say. Candidate, not yet on the page.

## How we'll know

- **Anchoring** of the answers, the same view asked several times on the same sources; reads
  outside the sources; the questions returned; what varies from one run to the next.
