# It compounds

Each turn leaves a source as well as a result, and the next turn starts from it: it costs less, or
comes out better.

"Both get it. Only one compounds." With agents, anyone who wants gets a result, structure or not.
The difference shows over time: without the structure, each request starts from zero; with it,
each request also leaves a source for the next. Across projects too: what one project made
explicit, the next one starts from. This is shown as a hypothesis, never as a promised curve.

## How we'll know

Five curves, read together: **reuse**, **fit** and **anchoring** go up; **corrections** and the
person's time per intent go down. Across projects, a new project draws on objects an earlier one
wrote. See [the measures](https://github.com/thevzion/standard/blob/main/standard/measures.md).
