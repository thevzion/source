# Anyone can start with seven types

Problem, why, vision, goal, project, task, decision: seven questions from four models are enough
to start, with no prior skill in structuring.

## How we'll know

- **Placement**, as trial 09 fixes it before running: of ten raw intents in a new space, how many
  land in the model's types, how many in local types (each with its question), and whether two
  agents place them the same way.
- The "Wrong place" signal, in [the measures](https://github.com/thevzion/standard/blob/main/standard/measures.md).
