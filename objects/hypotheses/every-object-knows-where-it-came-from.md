# Every object knows where it came from

The trace keeps what the agent read (`read`, observed) and what each object draws on (`draws on`,
declared). Each object knows where it came from, and what came from it. Candidate, not yet on the
page.

## How we'll know

- **Use**: the objects others draw on, and how often; those read but never drawn on.
- **Context**: the share of what was read that is drawn on, and what is drawn on without being
  read.

See [the measures](https://github.com/thevzion/standard/blob/main/standard/measures.md).
