# Does a sourced claim count in anchoring?

A claim that rests on a pointer is sourced: traceable, but it can be generic (a fact true for
everyone) without being invented. The trace separates specificity from traceability.

Settled by: [trial 13](https://github.com/thevzion/standard/blob/main/tests/trials/13-genericity.md) and
[trial 15](https://github.com/thevzion/standard/blob/main/tests/trials/15-trace.md).
