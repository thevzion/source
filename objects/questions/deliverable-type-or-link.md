# Is a deliverable a type, or a link?

Option: a link, where a project `delivers` an object of any model (a document, a publication,
code); a spec is a document, and becomes a deliverable because a project delivers it. This space
uses the type for now ([the site](../deliverables/site.md)).

Settled by: a decision, once there is more than one deliverable.
