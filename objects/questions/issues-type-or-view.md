# Are issues a type, or a view?

Proposed: a view. An issue is what was noticed and not yet filed: an idea goes to Knowledge (a
material), a friction or a bug is an observed result, a question goes to Loop, a thing to do
becomes a task. "To sort" becomes a view.

Settled by: whether this repository's GitHub issues, its inbox, file cleanly that way.
