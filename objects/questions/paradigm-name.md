# What do we call the paradigm?

Candidate: "intent as source", like "infrastructure as code": the intent is the source, the rest is
a projection of it. The plain names stay (the standard, a space, the trace). "Instruction as
source" is set aside: an instruction says how.

Settled by: whether readers get it without an explanation; then a decision.
