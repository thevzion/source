# The commit is the change

**Decision.** Git is the tool; Changes is the standard's abstraction. One commit is one change, and
an adapter can show it as one row of a Changes table.

**Why.** The history already holds who changed what, when and why; a second journal would be a copy
that drifts.

**Who answers.** The founder.
