# Explicit at the core

**Decision.** Make things explicit at the core, not only as document templates: one object per
question, typed, linked, dated, with its provenance; one change per commit, with its reason.

**Why.** When the agent pays, the structure no longer depends on the size of the team. And the flow
agents produce is reviewed in small units, what was inferred first; a template formats a document,
which is still read whole.

**Who answers.** The founder.

**See.** [The structure](../../standard/structure.md), [the doctrine](../../standard/doctrine.md).
