# Observe before constraining

**Decision.** An explicit, observable system, with very few constraints. Measure first; constrain
only later, if a measure warrants it. Checks flag smells, they don't block.

**Why.** A limit written before measuring encodes a guess about what the system will become.

**Who answers.** The founder.

**See.** [The doctrine](../../standard/doctrine.md), [the measures](../../standard/measures.md),
[which constraints are worth it](../questions/constraints-worth-it.md).
