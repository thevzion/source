# The Standard

The doctrine (how any intelligence behaves) and the structure (objects, links, changes, the trace,
truth, access), kept in [`standard/`](https://github.com/thevzion/standard/blob/main/standard/README.md).
The standard library ships with it, in [`models/`](https://github.com/thevzion/standard/blob/main/models/README.md),
with the setup prompt and the tests.

One structure anyone can take, and many can test. Its repository is
[`thevzion/standard`](https://github.com/thevzion/standard), apart from TheVZion's source
([decision](../decisions/two-repositories.md)).

Version 0.1, candidate, untested.
