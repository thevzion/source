# People learn how an organization works by playing, and come back for fun.

Written as an outcome, as goal 3 is ([decision](../decisions/goal-3-as-an-outcome.md)). It replaces
"A game that's fun on its own, and tests the structure.", which named a thing to deliver: the game
is [a project](../projects/game.md) that serves this goal.

## How we'll know

- Players replay without being pushed.
- Players can say, in their own words, something about how an organization works that they didn't
  know before.
