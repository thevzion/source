# scenario

**Question.** What would it look like, for someone, concretely?

**Horizon.** One scene: how it goes today, and how it goes once the loop between wanting and getting
is gone.

**Fields.**

| Field | What it holds |
|---|---|
| `before` | the loop today, as someone lives it |
| `imagine` | the same scene without the loop |
| `illustrates` | the hypothesis it makes concrete (a link) |
| `tested-by` | the trial that will check it (a link) |
| `evidence` | `hypothesis` while it is only imagined; `observed`, with its date, once a trial has seen it |

**Why a local type.** No installed type asks this question. A hypothesis asks what we believe and how
we will know; a goal asks what we want; a trial is the proof. A scenario shows the hypothesis as a
scene someone can picture.

**Honest by construction.** Every scenario links the hypothesis it illustrates and the trial that will
check it, and its evidence says whether it is still imagined or has been seen. Pages that show
scenarios are projections of these objects, never copy written apart.

**Desire path.** Local first. If the same type returns in other sources, it becomes a seed, then joins
a model, perhaps Loop, next to hypotheses.
