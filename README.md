# TheVZion's source

What TheVZion wants, why, and how it will know, written on [the standard](https://github.com/thevzion/standard)
as small objects any agent can read and run, every change with its reason.

## Run it

Clone it, point your agent at it, and ask what's next.
It knows what's decided, what's open, and why.

## What is here

| Path | What it is |
|---|---|
| [`space.md`](space.md) | what this space declares: the standard and the models it follows, truth, access |
| [`objects/`](objects/) | one object per question: problem, why, vision, goals, projects, decisions, hypotheses, open questions |
| `git log` | the journal: one change per commit, with `Why:` and `Source:` |

Start with [the vision](objects/vision.md), [the goals](objects/goals/) and [what's still open](objects/questions/).

## Propose a change

| For | Where |
|---|---|
| a goal, a decision, a question of TheVZion | an issue here: [Propose a change](.github/ISSUE_TEMPLATE/propose-a-change.md) |
| the standard, a model or a test | [the standard's issues](https://github.com/thevzion/standard/issues) |

A proposal becomes true only by a decision, written as a commit.
